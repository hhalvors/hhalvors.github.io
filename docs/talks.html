Talks

Slides from talks and lectures. The TeX and (Q)MD files are the source for the decks (Beamer and Quarto/Reveal.js respectively) — feel free to re-use them.

Open workshop: I use standard open-source tools to write these, e.g. pandoc. I’ve also played around with creating some further tools to simplify the process: nordisk (write Beamer slide decks in Markdown) and diagrams (for building the figures).
